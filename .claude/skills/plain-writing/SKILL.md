# 쉬운 글 편집 / Plain Writing
독자가 무엇을 알아야 판단할 수 있는지부터 정합니다. 결론 → 이유 → 방법 → 한계 순으로 자연스럽게 설명합니다. 짧은 글이면 불필요한 제목·목록을 추가하지 않습니다.
전문 용어는 필요한 것만 쓰고 처음에 풀이합니다. 한 문장에 핵심 하나를 담고, 수치는 단위·비교 기준과 함께 설명합니다. 글을 짧게 만들기 위해 필요한 배경을 지우지 않습니다.
사실/해석/가설, 원문의 조건, 불확실성, 반대 근거를 유지합니다. 출처를 관련 주장 가까이에 표시합니다. 긴 실행 로그는 본문 대신 부록/파일로 연결합니다.
편집 후 결재된 초안과 숫자·결론·조건·근거 사용을 대조합니다. 중요한 결과물은 작성자와 다른 작업자가 확인합니다. 의미가 바뀌면 초안 수정과 재결재를 요청합니다.
최종 파일은 outputs에 저장하고 `docs/RECORDS.md`의 editorial 기록에 실제 확인한 항목만 true로 남깁니다. 문장 길이 검사만으로 가독성을 보증하지 않습니다.
