# 자료 조사 / Source Research
조사 질문을 먼저 정하고 원자료/공식 발표/논문 원문을 우선합니다. 원문을 실제로 열고 제목·발행일·작성 주체·표 또는 문단 위치를 확인합니다. 검색 스니펫/초록/전문 중 읽은 범위를 구분합니다.
각 자료에 위치, 확인 시각, 읽은 구절/표, 질문과의 관련성, 제한을 남깁니다. 웹 주소를 모델 기억으로 만들어 넣지 않습니다. 재배포 기사는 원출처로 묶어 독립 근거 수를 부풀리지 않습니다.
자료를 내려받았다면 원본을 inputs에 보존하고 가공 파일은 work에 둡니다. API 수집은 요청 조건·기간·필드 정의·수집 누락을 기록합니다. 접근 실패를 출처 부재라고 판단하지 않습니다.
찬성 검색뿐 아니라 실패 사례·반박 연구·다른 설명을 찾습니다. 필요한 근거를 확보하면 반복 검색을 멈춥니다. 최신성이 필요한 주장은 확인일과 기준일을 구분합니다.
반환: 원문 위치 목록과 확인한 내용. 수집자의 출력은 검증자의 독립 판정을 대체하지 않습니다.
