# 예제

## 오프라인 기록 흐름

```bash
python3 examples/local_demo.py
```

임시 폴더에서 가상 원자료 → 근거 기록 → 결재 → 편집 확인 → 제출 검사를 수행합니다. AI를 호출하지 않으며 실제 조사 성능의 증거가 아닙니다. 완료 후 임시 폴더는 정리됩니다.

## 실제 에이전트 시험 요청

다음 과제는 도구 연결이 정상인지 확인하는 작은 시작점입니다. 민감한 실제 자료 대신 제공한 합성 자료를 사용합니다.

> 프로젝트 팀의 독립 검증자를 사용해 examples/fixtures/draft.md의 주장을 같은 폴더의 원자료와 대조해 주세요. 검증 스킬에 따라 반대 근거와 미확인 사항을 남기고 초보자가 이해할 수 있는 수정안을 제시해 주세요. 외부 검색이 필요한 사실은 이 로컬 자료로 검증했다고 쓰지 마세요.

이후 실제 업무 한 건에서 품질·호출 수·토큰·시간을 측정합니다. 단일 에이전트 결과와 비교한 뒤 검증의 개선이 없으면 역할이나 호출을 줄입니다.
