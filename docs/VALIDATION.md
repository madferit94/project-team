# 검증 범위

## 자동 검사

`python3 -m unittest discover -s tests -v`

의미 있는 불변 조건을 확인합니다: 미접근 출처의 확정 판정 차단, 미확인 주장의 사실 승격 차단, 반대 근거 항목 누락 차단, 결재 후 입력 변경 감지, 최종 파일 수정 감지, 프로젝트 밖 경로 차단, 작업 한도, 기록 수정 이력, 로컬 예제 통과.

`python3 scripts/sync_adapters.py --check`

공통 원본과 Codex/Claude 배포본이 같은지, TOML 형식이 유효한지 확인합니다. 두 앱이 실제 설정을 불러와 도구를 실행했다는 의미는 아닙니다.

## 행동 시험

examples/fixtures의 합성 원자료와 초안을 독립 검증자에게 전달합니다. 검증자는 답을 미리 받지 않고 source/data를 읽고 결과를 제출해야 합니다. 기대 결과는 테스트 관리자가 별도로 평가합니다.

측정할 것: 근거 없는 주장 발견, 올바른 주장 보존, 접근 실패 처리, 숫자 재계산, 쉬운 수정문, 실제 실행 여부, 사용량 제공 여부.

## 2026-10-05 실제 확인 결과

- Python 3.11.4에서 자동 검사 21개 통과.
- 스킬 작성 도구의 형식 검사: 공통 스킬 11개 통과.
- Codex/Claude 배포 파일 32개와 공통 원본 일치 확인.
- 오프라인 기록 예제 통과. 모델 호출 없음.
- 별도 하위 에이전트가 합성 원자료를 직접 읽고 재계산하는 행동 시험을 수행함. 주문 중복·합계·반품률·결측 상태의 오류 4개를 찾았고, 총괄 경험과 매출 개선 주장 2개는 확인 불가로 구분함. 제한적인 역량 해석은 보존함.
- 독립 재계산: 5행, 고유 주문 4건, 중복 제거 후 금액 합계 1,000. 반품 미확인을 미반품으로 가정하면 1/4=25%, 확인된 고유 주문만 보면 1/3 약 33.3%. 통화/상태 코드 정의 부재도 명시함.
- 행동 시험은 현재 채팅의 실제 하위 에이전트로 수행했으며, 새 저장소의 Codex/Claude 역할 설정 자동 발견을 시험한 것은 아님. 토큰/비용은 측정되지 않음.
- 발견한 개선점(로컬 자료의 실재와 실제 사건의 실재 구분, 작업 ID 연결, 프로젝트 내부 원문 경로)을 지침에 반영함.
- 설치된 Claude Code 2.1.97의 `claude --setting-sources project agents`에서 프로젝트 역할 10개를 실제 발견함. 모델 호출은 수행하지 않음.
- 설치된 Codex CLI 0.160.0의 `codex debug prompt-input`에서 project-team 스킬과 프로젝트 AGENTS.md가 실제 입력에 포함되는 것을 확인함. 역할 TOML의 실제 호출은 미검증.
