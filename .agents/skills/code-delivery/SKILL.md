# 코드와 분석 결과 / Code Delivery
입력/출력/한 행의 의미/키/완료 기준을 먼저 정하고 기존 코드를 읽습니다. 목적에 충분한 단순한 함수와 의존성을 선택합니다. 새 라이브러리 설치는 필요성을 확인합니다.
데이터 처리에서는 로딩 → 검증 → 정제 → 계산 → 시각화 → 저장 순으로 읽기 쉽게 작성합니다. 원본은 inputs에 보존합니다. 누락·중복·ID·범위·단위, 병합 전후 행 수/미매칭을 확인합니다.
작성자는 실제 명령·출력·실패를 반환합니다. 검토자는 독립 재계산이나 의미 있는 경계 사례로 결과를 확인합니다. 작은 수정에 전체 테스트를 반복하지 않습니다. 같은 파일을 여러 작업자가 동시에 편집하지 않습니다.
공식 통계와 파생 지표를 구분하고 계산 성공을 해석 타당성으로 간주하지 않습니다. 완료 시 코드, 재현 명령, 입력 버전, 검증 결과, 남은 한계를 남깁니다.
