# 프로젝트 설계 / Project Brief
목표, 독자, 결과물, 범위, 원자료, 완료 기준, 제한을 `brief.md`에 정리합니다. 필요한 정보가 없을 때만 핵심 질문을 묻고 독립 작업은 진행합니다.
문제를 결과/원인 후보/비교 조건처럼 같은 수준에서 분해합니다. MECE는 겹침과 빠짐을 줄이는 점검 기준이며 완벽한 분할을 강요하지 않습니다. 분류 기준과 예외를 적습니다.
요청 변경 시 원자료 버전과 변경 부분을 비교해 영향을 받는 근거·결정·문구만 재검토합니다. 다른 프로젝트 정보를 자동으로 혼합하지 않습니다.
주제 이름만으로 분야 전문가를 생성하지 않습니다. 도구·독립 검토·전문 규칙이 실제로 달라질 때만 추가합니다.
반환: 목표 한 문장, 핵심 질문, 완료 기준, 최소 역할, 현재 미확인 사항. 프로젝트 전체 요약은 짧게 유지합니다.
