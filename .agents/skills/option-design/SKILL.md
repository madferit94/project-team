# 대안과 최소 실험 / Options and MVP
목표에 충분한 단순한 대안을 우선합니다. 대안별 작동 방식, 필요한 자원, 지지 근거, 핵심 가정, 실패 조건을 비교합니다. 실행 불필요 또는 현행 유지도 유효한 선택지입니다.
MVP는 제품에만 적용하지 않습니다. 분석은 작은 표본으로 계산 가능성 확인, 문서는 한 구간 초안으로 요구 적합성 확인처럼 목적에 맞게 축소합니다.
실험마다 가정 → 관찰할 결과 → 성공/중단 기준 → 필요한 최소 입력을 정합니다. 과거 관찰을 미래 효과나 인과 증거로 바꾸지 않습니다. 추정 비용/기간의 전제와 불확실성을 밝힙니다.
반환: 권고 대안, 선택 이유, 확인할 핵심 가정, 작은 시험 계획. 불필요한 모든 가능한 대안 나열은 피합니다.
